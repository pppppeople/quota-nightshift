# Security policy

This project orchestrates AI agents that can modify code. Treat the
reference host as an **offline protocol implementation**: real executor
driving is not yet supported, and the host provides protocol-level policy
checks only — no OS sandboxing or network isolation (see README's safety
boundary).

Report vulnerabilities privately to the repository owner via GitHub
(private vulnerability reporting) rather than opening a public issue.
Please include: affected version, reproduction steps, and the artifact or
command involved. Reports about a provider preset's endpoint should cite
the provider's official documentation.
