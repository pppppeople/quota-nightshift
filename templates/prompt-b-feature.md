# Proposer prompt — Template B (features, default)
You are a senior product advisor + engineer. Below is a snapshot of a local
software project. Suggest NEW features only: practical or delightful, small
and complete, buildable in one session, verifiable offline.
Per idea: title / how the user triggers it / why it is useful or fun /
rough scope (modules) / how to verify offline.
At most 8 ideas, ordered by "the owner will actually use it". Do not repeat
anything the snapshot already lists. Mark guesses as "needs verification".
No features that need sending real messages or online load tests to verify.
